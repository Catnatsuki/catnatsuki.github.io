Spoticord

Discord bot to manage spotify playlists.

  • Spoticord is a discord bot which helps you manage shared playlists for your discord server!
  • Users can add songs to a shared playlist using slash commands.
  • Helps you limit the number of submissions per month with the help of a SQLite DB to track user submissions.
  • Default limit per month configured to 3.
